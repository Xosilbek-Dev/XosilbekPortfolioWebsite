# Personal Blog

A personal blog website built with **Vue.js 3** and **Tailwind CSS**.  
The site features a **contact form** and supports **English and Uzbek language selection**.

---

## 📂 Project Structure
- **/src** – Vue components and router
- **/public** – Static files (HTML, favicon, etc.)
- **vite.config.js** – Vite configuration
- **package.json** – Project dependencies and scripts
- **LICENSE.txt** – Custom license
- **README.md** – Project documentation

---

## ⚡ Technologies
- Vue.js 3  
- Vite  
- Tailwind CSS  
- HTML / CSS / JavaScript  
- Contact form (receives messages from users)  
- Multilingual support: English and Uzbek

---

## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/Xosilbek-Dev/XosilbekPortfolioWebsite.git

# Install dependencies
npm install

# Run the development server
npm run dev

# Open in your browser
http://localhost:5173
```
